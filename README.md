# Sistem Pakar Pengendali Suhu Fermentasi Tapai Ketan (Fuzzy Mamdani)

Repositori ini berisi *source code* Arduino untuk sistem kendali *closed-loop* yang dikembangkan dalam tugas akhir berjudul **"SISTEM PAKAR UNTUK MENGENDALIKAN SUHU RUANGAN DALAM PROSES FERMENTASI TAPAI KETAN MENGGUNAKAN FUZZY MAMDANI"**. 

Sistem ini dirancang untuk mengatasi masalah ketidakstabilan suhu pada proses fermentasi tapai ketan skala UMKM dengan menjaga suhu secara otomatis dan adaptif pada rentang optimal 35°C hingga 40°C..

## Perangkat Keras (Hardware)
Sistem ini diimplementasikan menggunakan media uji berupa kotak styrofoam berukuran 47 x 32 x 27 cm. Berikut adalah komponen utama yang digunakan:
1. **Mikrokontroler:** Arduino UNO
2. **Sensor Suhu:** DS18B20 (diletakkan di antara wadah bahan fermentasi)
3. **Aktuator/Pemanas:** Lampu Pijar
4. **Pengendali Daya:** Modul Dimmer AC
