# Sistem Pakar Pengendali Suhu Fermentasi Tapai Ketan (Fuzzy Mamdani)[cite: 1]

Repositori ini berisi *source code* Arduino untuk sistem kendali *closed-loop* yang dikembangkan dalam tugas akhir berjudul **"SISTEM PAKAR UNTUK MENGENDALIKAN SUHU RUANGAN DALAM PROSES FERMENTASI TAPAI KETAN MENGGUNAKAN FUZZY MAMDANI"**[cite: 1]. 

Sistem ini dirancang untuk mengatasi masalah ketidakstabilan suhu pada proses fermentasi tapai ketan skala UMKM dengan menjaga suhu secara otomatis dan adaptif pada rentang optimal 35°C hingga 40°C[cite: 1].

## Perangkat Keras (Hardware)
Sistem ini diimplementasikan menggunakan media uji berupa kotak styrofoam berukuran 47 x 32 x 27 cm[cite: 1]. Berikut adalah komponen utama yang digunakan:
1. **Mikrokontroler:** Arduino UNO[cite: 1]
2. **Sensor Suhu:** DS18B20 (diletakkan di antara wadah bahan fermentasi)[cite: 1]
3. **Aktuator/Pemanas:** Lampu Pijar[cite: 1]
4. **Pengendali Daya:** Modul Dimmer AC[cite: 1]
